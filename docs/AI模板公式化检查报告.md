# AI 模板公式化检查报告

目前共 29 项由公式引擎实际执行。本轮在此前12项基础上新增17项，包括截止倒计时、BMR、年龄、工龄、任务状态、月末、工时等。展示公式与实际执行公式同源，不调用模型、不消耗模型额度。

真实验证表：[AI 模板全量验证（142项）](http://localhost:5173/smart/table/81)。29项均已配置并落库复验通过；随机数检查范围而非固定结果。

## 公式清单

方括号为输入角色；复制到普通公式列时替换为实际字段名。空输入返回空；无效数字、负税基、非法日期和零分母会提示校验错误。

### 计算个人所得税

按月度换算税率表计算参考税额，输入为已扣除费用的月度应纳税所得额；不是居民工资累计预扣或年度汇算税额。

```text
ROUND(MAX(0,IFS([月度应纳税所得额（已扣除费用）]<=3000,[月度应纳税所得额（已扣除费用）]*0.03-0,[月度应纳税所得额（已扣除费用）]<=12000,[月度应纳税所得额（已扣除费用）]*0.1-210,[月度应纳税所得额（已扣除费用）]<=25000,[月度应纳税所得额（已扣除费用）]*0.2-1410,[月度应纳税所得额（已扣除费用）]<=35000,[月度应纳税所得额（已扣除费用）]*0.25-2660,[月度应纳税所得额（已扣除费用）]<=55000,[月度应纳税所得额（已扣除费用）]*0.3-4410,[月度应纳税所得额（已扣除费用）]<=80000,[月度应纳税所得额（已扣除费用）]*0.35-7160,TRUE,[月度应纳税所得额（已扣除费用）]*0.45-15160)),2)
```

### 计算个税档位

按月度换算税率表返回适用税率档位；输入是应纳税所得额，不是税前工资。

```text
IFS([月度应纳税所得额（已扣除费用）]<=3000,"3%",[月度应纳税所得额（已扣除费用）]<=12000,"10%",[月度应纳税所得额（已扣除费用）]<=25000,"20%",[月度应纳税所得额（已扣除费用）]<=35000,"25%",[月度应纳税所得额（已扣除费用）]<=55000,"30%",[月度应纳税所得额（已扣除费用）]<=80000,"35%",TRUE,"45%")
```

### 计算年终奖单独税率

全年一次性奖金除以 12 后，按月度换算税率表返回单独计税税率；输出税率而非税额。政策适用至 2027-12-31。

```text
IFS(([全年一次性奖金总额]/12)<=3000,"3%",([全年一次性奖金总额]/12)<=12000,"10%",([全年一次性奖金总额]/12)<=25000,"20%",([全年一次性奖金总额]/12)<=35000,"25%",([全年一次性奖金总额]/12)<=55000,"30%",([全年一次性奖金总额]/12)<=80000,"35%",TRUE,"45%")
```

### 计算年终合并税率

将奖金加到全年应纳税所得额后，按年度综合所得税率表返回边际税率；不是有效税率，也不代表奖金最终税额。

```text
IFS(([全年应纳税所得额（不含本次奖金，已扣除费用）]+[并入综合所得的奖金])<=36000,"3%",([全年应纳税所得额（不含本次奖金，已扣除费用）]+[并入综合所得的奖金])<=144000,"10%",([全年应纳税所得额（不含本次奖金，已扣除费用）]+[并入综合所得的奖金])<=300000,"20%",([全年应纳税所得额（不含本次奖金，已扣除费用）]+[并入综合所得的奖金])<=420000,"25%",([全年应纳税所得额（不含本次奖金，已扣除费用）]+[并入综合所得的奖金])<=660000,"30%",([全年应纳税所得额（不含本次奖金，已扣除费用）]+[并入综合所得的奖金])<=960000,"35%",TRUE,"45%")
```

### 计算年假额度

按累计工作年限计算标准全年年休假天数：不足1年0天，满1年5天，满10年10天，满20年15天。不包含入离职折算、已休抵扣及不享受年休假的特殊情形。

```text
IFS([累计工作年限（年）]<1,0,[累计工作年限（年）]<10,5,[累计工作年限（年）]<20,10,TRUE,15)
```

### 计算当前库存

```text
ROUND([期初库存]+[入库数量]-[出库数量],4)
```

### 库存状态预警

```text
IFS([当前库存]<=0,"缺货",[当前库存]<[安全库存],"偏低",TRUE,"充足")
```

### 计算生产总工时

根据 {input} 的内容，根据人数与时长计算总工时（小时），只返回数字。

```text
ROUND([人数]*[工作时长（小时）],2)
```

### 计算批次不良率

不良数量 ÷ 批次总数 × 100；总数为零或不良数量超出总数时提示错误。

```text
ROUND([不良数量]/[批次总数]*100,2)
```

### 判断出勤是否达标

根据 {input} 的内容，根据出勤天数与应出勤天数判断是否达标（≥95%）。

```text
[实际出勤天数]/[应出勤天数]>=0.95
```

### 计算 BMI

根据 {input} 的内容，根据身高与体重计算 BMI（体重kg / 身高m²），保留一位小数。

```text
ROUND([体重（千克）]/([身高（厘米）]/100)^2,1)
```

### 计算基础代谢率

根据 {input} 的内容，根据性别、年龄、身高、体重按 Mifflin-St Jeor 公式计算基础代谢率（千卡）。

```text
IF(OR([身高（厘米）]<=0,[体重（千克）]<=0,[年龄（周岁）]<0),"",IF([性别（男 / 女）]="男",ROUND(10*[体重（千克）]+6.25*[身高（厘米）]-5*[年龄（周岁）]+5,0),IF([性别（男 / 女）]="女",ROUND(10*[体重（千克）]+6.25*[身高（厘米）]-5*[年龄（周岁）]-161,0),"")))
```

### 任务截止倒计时

```text
IF(ISBLANK([到期日期]),"",IF([到期日期]<=TODAY(),"",DATEDIF(TODAY(),[到期日期],"D")))
```

### 判断任务状态

根据 {input} 的内容，根据任务信息判断其当前状态。

IF(NOT(ISBLANK([实际完成日期])),"已完成",IF(ISBLANK([实际开始日期]),"未开始",IF(ISBLANK([计划完成日期]),"进行中",IF([计划完成日期]<TODAY(),"已延期","进行中"))))

### 判断合同状态

### 计算健康证到期天数

### 计算增值税申报截止日

所属期次月15日，遇周末顺延至周一。仅为申报截止日参考，法定节假日及税务机关公布的延期需另行核对。

```text
DATEADD(DATE(YEAR(EDATE([所属期日期],1)),MONTH(EDATE([所属期日期],1)),15),IF(WEEKDAY(DATE(YEAR(EDATE([所属期日期],1)),MONTH(EDATE([所属期日期],1)),15),2)>5,8-WEEKDAY(DATE(YEAR(EDATE([所属期日期],1)),MONTH(EDATE([所属期日期],1)),15),2),0),"day")
```

## 检查结论

- 截止倒计时改为数字：截止日期晚于今天时返回自然日差；空日期、到期当天及已过期返回空。验证表的输出类型同步更新为数字。业务表中的旧倒计时字段需重新保存模板配置，以更新原来的文本输出类型。
- 扩展公式函数 NETWORKDAYS_CN（中国节假日与调休）及 DATEDIF 的 S 单位（精确秒数，无时区按北京时间），普通公式列也可使用。原 NETWORKDAYS 的周一至周五规则保持不变。
- 本轮后端44项回归通过；涵盖日期空值、当日、逾期、闰日、调休、跨时区工时及数字转换，并断言不调用旧计算分支或模型。
- 可表达的单行规则由公式执行；身份证校验、文本编码、农历、多人交集跨行汇总及文件处理等保留本地算法（没有硬套会改变语义的公式），均不调用模型。语义分类、摘要、OCR、风险分析等保留模型。
- 增值税模板原实现误解为税额计算，已按参考图纠正为申报截止日；周末顺延不等于实际法定申报期限。
- 参考图中月度税额示例不全正确：应纳税所得额9200元按10%减210，应为710元，不是截图的620元。按规则修正，不照抄错误示例。
- 年终奖合并采用年度综合所得口径，输入为扣除费用后的全年所得额与奖金，不将全年奖金直接套月度工资档位。
- 修复公式引擎幂运算优先级：70/(175/100)^2 现在为22.857…，不再按低优先级异或语法分组。字符串中的^保留原样，SQL求值同步支持。
- 已有六类模型配置需要重新绑定结构化输入；旧自然语言描述不能当作税基或工龄，系统会校验并报错，不再让模型推测。此次只自动更新合成验证表，未批改业务表数据。
- 原全量验证报告记录的是此前模型执行结果，本报告及最新验证数据中的 calculation 记录为本次公式复验结果。
