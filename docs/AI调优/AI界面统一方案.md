## 二、不一致点（问题清单）

1. **主按钮位置/文案/样式不统一**：右下「生成」是主流（导图/画板/记事本），但报表在**左下且是紫色实心**（截图里视觉重心错位），工作流是「生成并进入画布」，节点配置是「生成并填入」。
2. **快捷键只有记事本有**（Enter/Esc），其余对话框全没有。
3. **模式选择三种形态**：画板 radio-button 五档、导图 radio 三档、报表靠系统猜（无模式）。用户跨模块要重新学一遍。
4. **图片支持参差**：导图/画板/记事本/助手支持（且都支持"只传图不写字"），报表/工作流不支持。
5. **加载预期管理不一致**：导图明确写"几秒到十几秒"、报表有"AI 设计中…"，其余只有按钮 loading 转圈。
6. **结果确认力度不一**：记事本有预览+插入（最稳）、助手有动作卡片确认、画板替换前确认；导图/报表/工作流直接应用（报表直接跳设计器，覆盖风险最高）。
7. **示例引导只有工作流有**（"试试："示例链接），其余全靠 placeholder。
8. **入口命名**：「AI 生成」「✨ AI 写作」「AI 帮我设置」「AI 配置」并存；图标 ✨/MagicStick/无 混用。

## 三、统一方案

### 3.1 原则

- **同一心智模型**：描述要什么（可附图）→ 生成 → 看结果 → 确认应用。所有入口都长这样。
- **形态二选一**：居中对话框为默认；只有"贴着上下文写作"的场景（记事本）保留浮动面板，但输入区视觉与对话框一致。
- **破坏性必确认**：替换/重建类（导图重建、画板替换、报表整表）执行前统一确认文案：「将替换当前 xx 内容」。

### 3.2 组件级落地：抽一个 `AiPromptDialog`

现状五个对话框各自手写（导图/画板/报表/工作流/节点配置），结构高度雷同。抽公共组件，业务方只传差异：

```
<AiPromptDialog
  v-model="visible"
  title="AI 生成思维导图"
  placeholder="描述导图主题…"
  :modes="[{value:'rebuild',label:'重建整图'}, ...]"   // 可选；有就显示 radio-button（样式统一用画板那款）
  :examples="['每天早上…']"                            // 可选；chips 可点填入（工作流的"试试"升级成统一部件）
  :image="true"                                        // 是否带 AiImagePicker
  submit-text="生成"                                   // 默认「生成」；特殊场景可传「生成并填入」
  :loading="loading"
  hint="生成后节点会逐个出现在画布上…"                  // 可选
  @submit="onSubmit"
/>
```

统一规范（写进组件默认值，业务方不传就是这个样）：

| 项 | 规范 |
|---|---|
| 宽度 | 520px |
| 主按钮 | 右下角「生成」（主色实心），左「取消」 |
| 快捷键 | Ctrl+Enter 提交（textarea 里 Enter 换行）、Esc 关闭；纯输入场景（助手/记事本面板）保留 Enter 提交 |
| 图片 | 统一 AiImagePicker；有图无字 = 按图生成（已实现，推广到报表/工作流） |
| 模式 | 有模式就用 radio-button（自动判断永远排第一且默认选中） |
| 加载反馈 | 按钮 loading + hint 区显示「AI 生成中，可能需要十几秒…」 |
| 结果 | 生成类直接应用（支持 Ctrl+Z 撤销的场景不弹确认）；替换/重建类先弹确认；汇总类出只读对话框+复制；写作类保留预览→插入 |
| 入口 | 统一「✨ AI 生成」命名；图标用 ✨（MagicStick 弃用） |

### 3.3 逐个界面的迁移动作

| 界面 | 动作 |
|---|---|
| 报表 AI 生成（列表页） | 迁入 AiPromptDialog——**主按钮挪回右下角**、去紫色；加图片支持（截图表格直接建报表） |
| 工作流 AI 生成 | 迁入；示例链接改为组件 examples chips |
| 报表块级 / 工作流节点 AI 配置 | 迁入（submit-text="生成并填入"）；标题统一「AI 生成 · 明细表」风格 |
| 思维导图 | 已在该形态；模式 radio 换成 radio-button 样式与画板对齐 |
| 画板 | 基准实现，不动 |
| 记事本 | 保留浮动面板；chips/图片/输入区样式对齐组件规范 |
| 助手 | 不动（会话式，另一种心智） |
| 导入向导 / 拍照识别 | 不动（无提示词交互） |

### 3.4 收益与工作量

- 抽组件后 5 个对话框收敛为 1 个，后续加"图片支持/快捷键/字数限制"改一处全生效
- 预估工作量：组件 0.5 天 + 迁移 4 处各 0.5~1 小时 + 回归

## 四、建议优先级

1. **P0**：报表 AI 生成对话框（按钮位置/颜色是最刺眼的例外）+ AiPromptDialog 抽取
2. **P1**：工作流生成 + 两个"AI 配置/设置"小对话框迁入；导图模式改 radio-button
3. **P2**：报表/工作流加图片输入；加载反馈文案统一
