# 定价与套餐设计（个人云 / 企业云 / 私有化）

> 状态：分析稿 ｜ 2026-10-10
> 关联：`docs/用户与权限体系设计.md`（套餐权益 plan_entitlements 与权限功能分档的落地模型）
> 结论先行：三条产品线（个人云 / 企业云 / 私有化）骨架成立。但分档不能只用"数量配额"
> 一个维度——需要**总条数口径 + 存储配额 + 功能分档（尤其权限体系）+ 免费版/试用 +
> 明确的超限到期规则 + 私有化年维保**六个补丁。

## 1. 产品线总览

| 产品线 | 形态 | 计费方式 | 目标客群 |
|---|---|---|---|
| 个人版（云） | SaaS 多租户 | 按档订阅（年付为主，月付锚定） | 个人、自由职业者 |
| 企业版（云） | SaaS 多租户 | **按人/年** + 最低起购，人数决定单价阶梯 | 5~200 人小企业 |
| 私有化部署 | 单租户实例（同一套代码） | License（按用户规模阶梯）+ 年维保 + 实施费 | 有数据合规/内网要求的企业 |

## 2. 全局计费原则

1. **记录数按工作区总条数计量，不按单表**。单表只设技术性软上限（如 50 万）防失控。
   （"每表 X 条"会出现 A 表爆了、B 表空着的惩罚式体验，且难解释、难计量。）
2. **存储空间单独配额**（附件/图片是真实成本大头，记录条数几乎免费）。
3. **外部填写者免费**：通过公开链接填表/提交工单的人不占席位、不算用户（工单/表单场景的标配卖点）。
4. **企业版按人/年计费，不整档锁死**（"10/50/100 人档"会让 11 人的公司被迫买 50 人档而流失）。
5. **年付价 = 10 个月月付价**：月付做锚点，主推年付，改善现金流。
6. **三档中中间档为主推**，页面标"最受欢迎"；低档锚定性价比，高档衬托中档。
7. **任何情况下不因欠费/超限删除用户数据**——口碑底线，也是销售时的信任牌。

## 3. 个人版（云）

> 价格为锚点示例，需对照简道云/明道云/SeaTable/Airtable 现价与自身成本校准后定稿。

| | 免费版 | 基础版 | 标准版 ⭐主推 | 高级版 |
|---|---|---|---|---|
| 价格 | 0 | ~¥99/年（¥9.9/月） | ~¥239/年（¥23.9/月） | ~¥499/年（¥49.9/月） |
| 表数量 | 3 | 20 | 100 | 不限 |
| 总记录数 | 5 千 | 5 万 | 50 万 | 200 万 |
| 存储空间 | 0.5 GB | 5 GB | 20 GB | 100 GB |
| 打印模板 | 1 个 | ✓ | ✓ | ✓ |
| 自动化 / API / 批量导入导出 | — | — | ✓ | ✓ |
| 回收站 / 版本历史 | — | 7 天 | 30 天 | 90 天 |
| 支持 | 社区 | 工单 | 工单优先 | 专属 |

免费版是获客渠道而非成本负担；个人版→企业版的升级路径要保留（个人租户可一键升级为企业租户，数据随迁）。

## 4. 企业版（云）

按人/年计费，**最低 5 人起购**；人数阶梯折扣示例：5–19 人原价，20–49 人 9 折，50 人以上 8 折。

| | 团队版 | 标准版 ⭐主推 | 旗舰版 |
|---|---|---|---|
| 单价 | ~¥120/人/年 | ~¥240/人/年 | ~¥400/人/年 |
| 总记录数 | 50 万 | 200 万 | 500 万+（可议价） |
| 存储空间 | 50 GB 起，按人累加 | 200 GB | 500 GB |
| 用户组 / 表级分享 | ✓ | ✓ | ✓ |
| **角色 + 数据范围矩阵 + OWD** | — | ✓ | ✓ |
| **共享规则 + 权限诊断** | — | — | ✓ |
| 字段级权限 | — | — | ✓ |
| 审计日志 | — | ✓（90 天） | ✓（不限） |
| 专属客服 / 实施协助 | — | — | ✓ |

- 权限体系（数据范围/OWD/共享规则/诊断/字段权限）是**付费分档的核心武器**——开发投入直接变成收入梯度。
- 企业试用：**14~30 天全功能试用**（旗舰权益），到期需选择付费档。

## 5. 私有化部署

一次性卖断 = 放弃持续收入 + 承担无限期支持义务，拆三笔收费：

| 项目 | 说明 |
|---|---|
| License 费 | 按用户规模阶梯：≤50 用户 / ≤200 用户 / 不限，各定一档价 |
| 年维保费 | License 的 15~20%/年，含版本升级 + 远程支持；**不买维保则停在当前版本** |
| 实施/定制费 | 上门部署、数据迁移、定制开发另计 |

私有化版功能 = 旗舰版全集 + 不限配额。代码与 SaaS 同源（私有化 = 只有一个租户的实例），套餐层在私有化下全开。

## 6. 超限、到期与降级规则（纠纷高发区，必须写进价格页与协议）

| 场景 | 行为 |
|---|---|
| 接近配额（80%） | 站内 + 邮件提醒，引导升级 |
| 超配额 | 7~30 天宽限期（每日提醒）→ 之后**禁止新增**，已有数据可读、可导出 |
| 到期不续费 | 降级为免费版配额口径，超额部分**只读保留**，不强制删除 |
| 降级（高档退低档） | 同上：已有超限数据只读保留 |
| 长期欠费 | 保留 N 个月（如 6 个月）供导出，之后才可清理，且清理前多次通知 |

## 7. 数据模型

```python
plans                # code / name / audience(individual|enterprise|private)
                     # price_monthly / price_yearly / sort
plan_entitlements    # plan_id + key + value，如：
                     #   max_tables / max_rows / max_storage_mb / max_seats / min_seats
                     #   feature_print_templates / feature_automation / feature_api
                     #   feature_data_scope / feature_owd / feature_share_rules
                     #   feature_perm_diagnose / feature_field_perm / feature_audit
                     #   trash_retention_days / audit_retention_days
subscriptions        # tenant_id + plan_id + seats
                     # status: trial / active / grace / expired
                     # started_at / expires_at
usage_counters       # tenant_id + table_count / row_count / storage_bytes / seat_count
                     # 写入路径维护缓存值 + 定时全量校准（避免每单 count 全库）
```

## 8. 校验点收口（entitlement 模块，单点）

| 时机 | 校验 |
|---|---|
| 建表 | max_tables |
| 写入记录（含导入、表单提交） | max_rows（总条数口径） |
| 上传附件 | max_storage_mb |
| 邀请成员 | max_seats |
| 进入角色矩阵 / OWD / 共享规则 / 权限诊断 / 审计页 | feature_*（前端隐藏 + 后端 403 双重） |

与权限判定同一原则：**收口于一处，切忌散落到各 router**。

## 9. 套餐 ↔ 权限功能映射

| 功能 | 个人版 | 企业团队版 | 企业标准版 | 企业旗舰版 |
|---|---|---|---|---|
| 表分享给指定人 | ✓ | ✓ | ✓ | ✓ |
| 用户组 / 组分享 | 隐藏 | ✓ | ✓ | ✓ |
| 角色 + 数据范围矩阵 | 隐藏 | — | ✓ | ✓ |
| OWD 默认共享 | 隐藏 | — | ✓ | ✓ |
| 共享规则 / 权限诊断 | 隐藏 | — | — | ✓ |
| 字段级权限 | 隐藏 | — | — | ✓ |
| 审计日志 | — | — | ✓ 90 天 | ✓ 不限 |

个人版所有"多人协作权限"子系统整体隐藏（单人使用无意义），产品上是两个皮肤，代码上是一套。
