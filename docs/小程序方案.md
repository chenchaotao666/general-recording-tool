微信开发者工具（官方模拟器）

uni-app 编译成微信小程序后，用微信开发者工具在电脑上运行调试，这是官方免费的：

- ✅ Windows / macOS 都有
- ✅ 内置模拟器：可选各种机型（iPhone/安卓尺寸）、切换网络环境、模拟定位/扫码等
- ✅ 完整调试能力：Console、Network 抓包、WXML 结构审查（类似浏览器 DevTools）
- ✅ 真机预览：生成二维码，手机微信扫码就能在真机上跑，不用发布

和 uni-app 的配合流程

uni-app 源码
   │  编译（HBuilderX 一键 / CLI: npm run dev:mp-weixin）
   ▼
dist/dev/mp-weixin 目录
   │  用微信开发者工具打开这个目录
   ▼
模拟器里运行，改代码自动热更新

两种开发方式任选：

1. HBuilderX（DCloud 官方 IDE）：图形界面，"运行 → 运行到小程序模拟器 → 微信开发者工具"一键搞定，会自动调起微信开发者工具
2. 命令行（vue-cli/vite 模式）：npm run dev:mp-weixin 编译监听，然后手动在微信开发者工具里打开输出目录——如果你习惯 VS Code 开发选这种

几个上手前要知道的点

1. AppID：正式小程序要在微信公众平 "测试号"，不注册也能跑，只是部分能力受限（如登录、支付）
2. 请求域名：模拟器里可以勾选"不校验合法域名"直接调你的局域网后端（http://电脑IP:8000），但真机预览和正式发布必须 HTTPS + 备案域名 发期没有影响
3. 如果以后还想上支付宝/抖音小程序，它们也各有类似的开发者工具，uni-app 同一套代码换个编译目标就行

所以你电脑上的开发体验会是：VS Code/HBuilderX 写代码 → 微信开发者工具里实时看效果 → 偶尔扫码在真机上验证，整个流程不需
