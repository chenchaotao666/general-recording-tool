## 二、占位符语法（模板里已布好）

- 主表：`{customer}` `{address}` `{phone}` `{contact}` `{order_no}` `{delivery_date}`
  `{order_date}` `{contract_no}` `{vehicle_no}` `{pay_method}` `{ship_method}` `{handler}` `{remark}`
- 内置：`{_id}` `{_today}` `{_total_cn}`（人民币大写）
- 明细循环：`{items._index}` `{items.order_no}` `{items.product_no}` `{items.name}` `{items.spec}`
  `{items.model}` `{items.color}` `{items.material}` `{items.unit}` `{items.qty}` `{items.price}`
  `{items.amount}` `{items.weight}` `{items.remark}` 等（行业专属列如 `{items.packs}` `{items.tax}` 同理）
- 明细合计：`{items.qty#sum}` `{items.amount#sum}` …
- 平表（无子表）也可用 `{_row.字段名}` 整表明细语法

> 上传到数据表前，把占位符里的字段名改成你表里的实际字段名。

## 占位符语法（模板里已布好）

- `{字段名}`：主表字段值，如 `{customer}` `{order_no}` `{delivery_date}`
- `{_id}` `{_today}` `{_total_cn}`：记录 ID / 打印当天 / 明细金额人民币大写
- `{items.列名}`：明细循环——所在行按明细行数自动向下复制展开（样式/合并单元格随行）
- `{items._index}`：明细序号；`{items.列名#sum}`：明细列合计；`{items._count}`：明细行数

## 使用注意

1. **占位符字段名要改成你表里的实际字段名**：这些模板用的是通用名
   （customer/address/contact/phone/contract_no/delivery_date/handler/vehicle_no… 和
   items 子表的 name/spec/unit/qty/price/amount/remark/color/material/product_no/order_no）。
   你的数据表字段名不同的话，在 Excel 里全局替换即可；子表名不是 `items` 时把 `{items.` 替换为 `{你的子表字段名.`。
   未识别的占位符会原样保留，方便检查。
2. **公司名/地址/电话是截图里的示例文字**，替换成自己公司的。
3. 整行内容恰好是 `{items.qty}` 这类单个占位符且字段是数值类型时，填充后是真数字，
   可以在 Excel 里继续用公式（如再乘税率）。
4. 想要"固定高度的空白补足行"：在明细循环行下方加几行带边框的空行即可，
   循环展开时它们会自动被推到明细数据之下（H228/H527/T100 已内置）。
5. `generate_templates.py` 是生成脚本（`backend/.venv` 的 Python 可跑），
   改排版细节（列宽/字体/行数）后重新执行即可重新生成全套。

## 打印流程

数据表页头「打印」→ 选该 Excel 模板 → 确定 → 下载填充好的 xlsx
（每条记录一个工作表，按单号命名）→ 在 Excel/WPS 中预览打印。
