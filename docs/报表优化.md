# 报表模块优化清单（P0 / P1 / P2）

> 来源：2026-09-23 对标业界轻量 BI / 低代码仪表盘（Metabase、DataEase、简道云仪表盘、飞书多维表格仪表盘）的差距分析。
> 定位：通用记录工具的报表模块，按"性价比"排优先级——先通用性核心，再表达力，最后工程量大的按需项。

## 差距分析摘要

| 能力维度 | 业界通用做法 | 优化前现状 |
|---|---|---|
| 聚合方式 | + 去重计数、占比、条件聚合 | 仅 count/sum/avg/max/min |
| 对比分析 | 同比/环比是标配 | 无 |
| 时间口径 | + 今天/昨天/近7天/近30天/本季/今年 | 仅周/月 4 种 + 自定义 |
| 查看端交互 | 查看者自助筛选、图表下钻、联动 | 仅时间口径切换 |
| 多指标 | 一图多系列叠加对比 | 单指标单系列 |
| 推送渠道 | 邮件/企业微信/钉钉/webhook | 仅邮件 |
| 数据源 | 多表关联、自定义 SQL | 单表绑定 |
| 计算字段 | 表达式列 | 无 |
| 布局 | 拖拽栅格、多页签 | 垂直堆叠 |

## P0 —— 通用性核心（✅ 已完成，`7fd3ac9`）

1. **查看端筛选组件**：模板声明 `filter_fields` 开放字段，查看者自助过滤而不改模板；筛选恒 AND 叠加在区块筛选之上，未声明字段一律拒绝（防越权过滤）
2. **去重计数 + 占比**：`count_distinct`（任意字段）；`ratio` 占比% = 满足区块筛选的记录数 ÷ 口径内总数（仅统计卡）
3. **时间口径补齐**：今天 / 昨天 / 近7天 / 近30天 / 本季度 / 今年；查看页改回按钮组切换
4. **环比卡片**：统计卡 `compare: true` → 与等长上一期对比（如本周 vs 上周），展示 ↑↓ 百分比

## P1 —— 表达力

5. **多系列图表**（✅ `6314788` + 修复 `f458af5`）
   - `metrics` 多指标（≤5 个，每项一个系列，与顶层 agg/field 互斥）
   - `group2` 二级分组（该字段每个取值一个系列，top 8 其余合并"其他"）
   - `stack` 堆叠（柱/折线/面积）；`chart_type` 新增面积图
   - 结果新增 `series[]`，保留 `values` 兼容；饼图禁多系列
6. **透视表区块**（✅ 本次完成，P1 中工程量最大）
   - `pivot` 区块：`row` × `col` 两个维度（均支持 field/day/week/month）交叉聚合，单指标（count/count_distinct/sum/avg/max/min，无 ratio）
   - field 型维度按记录数取 top N（行默认 30 ≤ 100、列默认 8 ≤ 20），其余合并"其他"；计数并列按 key 升序打底，双引擎次序一致
   - 行列合计 + 总计独立聚合（含"其他"桶记录，avg/去重语义正确）；`totals: false` 可关闭
   - 下钻复用 drill 协议：`group_index`=行、`series_index`=列，合计行/列传 null；chart 行为不变
   - 消费方全覆盖：查看页/小程序点单元格下钻、xlsx 矩阵导出、HTML/邮件矩阵表、Webhook Markdown 摘要
7. **图表下钻**（✅ `edade4a`）
   - `POST /api/reports/{id}/drill`，按 `group_index`/`series_index`（对齐图表 labels/series 下标）取该单元明细
   - 沿用图表的完整口径（时间范围、区块筛选、查看端筛选）；"其他"桶/空值桶可下钻
   - 前端点击图表弹明细表格；小程序按住看图、松手下钻出底部弹层
8. **推送接企业微信/钉钉 webhook**（✅ `d6eb264`）
   - `push.webhooks: [{type: wecom|dingtalk|custom, url}]`，与邮箱渠道并存
   - 推送 Markdown 摘要（统计卡含环比、图表/明细前 10 行）；多渠道独立发送，单渠道失败不阻塞，错误汇总落 `ReportRunLog`

## P2 —— 工程量大，按需（⬜ 均未开始）

9. **多表关联 / 跨表指标**：需要设计 join 配置，复杂度陡增
10. **计算字段**：表达式引擎（如 合格率 = 合格数 / 总数）
11. **拖拽布局**：栅格化自由尺寸、多页签仪表盘
12. **PDF/图片导出、iframe 嵌入**

## 配套基建（本轮同步完成）

- SQL / JSON 双存储引擎语义对齐，冒烟测试覆盖所有新能力（`backend/smoke_test.py` 10.5~10.9 节）
- 图表分组布局计算抽为 `_chart_layout_sql`、透视表维度布局抽为 `_dim_keys_sql` 共用，保证渲染与下钻口径一致
- AI 辅助生成报表的提示词同步支持全部新配置项
