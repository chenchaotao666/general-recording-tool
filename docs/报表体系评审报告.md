## 二、与业界优秀产品的差距

### 2.1 总览表

| 维度 | 业界标杆做法 | 本产品现状 | 差距 |
|---|---|---|---|
| 图表类型 | 20~40 种（散点、漏斗、雷达、地图、组合图、瀑布、词云…） | 5 种 + 仪表盘 | 🔴 大 |
| 快速计算 | 同比/环比/占比/累计/排名（表计算）一键切换 | 仅环比（统计卡） | 🔴 大 |
| 图表交互 | 缩放（dataZoom）、图例开关、单图导出、悬停富提示 | 仅点击下钻/联动 | 🟡 中 |
| 透视表 | 行列互换、展开折叠、点击列头排序、条件格式色阶 | 静态矩阵 + 下钻 | 🟡 中 |
| 明细表 | 服务端分页、列冻结、列宽拖拽、单元格条件格式 | 客户端分页，无冻结/格式 | 🟡 中 |
| 数据建模 | 自定义 SQL、跨源 blending、星型模型 | 单表 + 左连接 ≤3 + 计算字段 | 🟡 中 |
| 钻取 | 层级钻取（省→市→区）、跳转其他报表 | 单层明细下钻 | 🟡 中 |
| 筛选器 | 级联筛选、筛选器间联动、树形筛选 | 独立筛选块，互不联动 | 🟡 中 |
| 告警 | 阈值告警（值超线自动推送） | 无（定时推送是固定内容） | 🟡 中 |
| 样式主题 | 配色主题、字体、背景、Logo、自定义 CSS | 固定白底默认风 | ⚪ 低 |
| 导出嵌入 | PDF / 图片导出、iframe 嵌入、开放 API | xlsx / html | ⚪ 低 |
| 协作 | 评论、版本历史、协同编辑 | 无版本历史（保存即覆盖） | 🟡 中 |
| 权限 | 行级权限（RLS）、分享可见范围控制 | 表级权限 + 分享链接 | ⚪ 低 |
| 性能 | 结果缓存、增量刷新、大数据量抽稀 | 每次实时全量计算 | 🟡 中 |

### 2.2 重点差距详述

**🔴 G1. 图表类型偏少。** 5 种图表 + 仪表盘是"周报够用"水平，但用户常见诉求里的漏斗（转化分析）、散点（相关性）、组合图（柱=量、线=率，双轴）、雷达（多维对比）都缺失。其中**组合图（柱线双轴）性价比最高**——多指标场景"金额用柱、达成率用线"是报表刚需，现有架构（echarts + series 数组）上加 `chart_type: 'mixed'` 工作量不大。

**🔴 G2. 缺少同比和快速计算。** 目前只有统计卡的环比；图表上看不到"本月 vs 去年同月"，也没有"占总计百分比""累计值""排名"。Tableau 的表计算、FineBI 的快速计算是用户感知最强的分析能力。建议先做两个低成本的：① 图表/透视表的**同比**（engine 里已有环比的上一期计算逻辑可推广）；② 统计卡/图表的**占总计比**（ratio 已有雏形，推广到 chart 系列值）。

**🟡 G3. 图表交互单薄。** 柱状/折线数据点多了之后没有缩放（echarts `dataZoom` 一行配置的事）；没有"下载当前图为 PNG"（echarts toolbox 自带）；tooltip 是默认样式。这三个都是 echarts 配置级改动，收益立竿见影。

**🟡 G4. 无版本历史与协同。** 保存即覆盖，改坏了回不去。工作流已有类似教训（后来加了体检/撤销）。最低成本方案：保存时把旧版 `blocks_json + layout_json` 快照进历史表，提供"查看历史 + 恢复"。

**🟡 G5. 无告警能力。** "库存低于 10 自动通知我"这类诉求目前要绕道工作流实现。报表侧可以在推送配置里加"仅当统计卡 X 满足条件时发送"，复用现有调度与推送管道。

**⚪ G6. 主题/嵌入/PDF 属于锦上添花**，与本产品"轻量记录工具"的定位匹配度低，不建议近期投入。

## 三、易用性问题与优化建议

> 维度：新手上手 → 设计器操作 → 概念理解 → 查看端 → 分发分享。以下问题均来自代码走查与近期迭代中发现的真实障碍。

### 3.1 新手上手

**🔴 U1. 报表没有模板市场，冷启动只有 AI 一条路。**
工作流已有模板市场（零输入安装 + 示例数据 + 默认停用防误触），报表却只有「新建空白」和「AI 生成」。AI 生成质量不稳定时用户无路可退。
**建议**：移植工作流模板市场的成熟模式——内置 6~10 个场景报表模板（销售周报、库存监控、客户跟进、生产日报…），一键安装（含自动建表 + 示例数据），用户从"改模板"上手而不是"从零搭"。这是性价比最高的易用性改动。

**🟡 U2. AI 生成是"全量替换"，不能渐进追加。**
`aiApply` 会替换全部区块并重排布局（`ReportLayoutDesigner.vue:1232`），用户想"在现有报表上加一个图"只能手动。建议 AI 对话框增加模式选择：「替换全部」/「追加为新页签」/「追加到当前页」。

**🟡 U3. 空画布引导可以更主动。**
现在空画布只有一行灰字提示。建议空态放 3 个引导卡：「拖字段成图」「AI 一句话生成」「从模板开始」，点击即触发对应动作。

### 3.2 设计器操作

**🔴 U4. 无撤销/重做。**
设计器的 `commit()` 只标脏，没有快照栈；删区块、删页签、自动排版都是不可逆操作（有确认弹窗但确认后无法恢复）。工作流已上过 undo/redo 的课。
**建议**：对 `(blocks, datasets, pages)` 做快照栈（结构化 JSON，体积小），Ctrl+Z / Ctrl+Y + 顶栏按钮。这是设计器类工具的及格线。

**🟡 U5. 改配置后要手动点「应用并绘制」，不会自动刷新。**
拖字段/AI 生成会自动取数，但在右侧面板改配置（换聚合、换分组）不会触发重绘，用户常以为"改了没反应"。建议：配置变更防抖 800ms 自动重绘当前块（保留手动按钮兜底），或在块标题栏加"配置已变更，点击刷新"的小标记。

**🟡 U6. 配置不完整的块静默跳过绘制，原因不可见。**
`buildDraft` 会把半成品块（筛选没选字段、透视表缺维度）过滤掉再提交草稿（`ReportLayoutDesigner.vue:966`），画布上该块只显示"点右侧应用并绘制加载数据"——用户配错了也不知道差哪一项。
**建议**：画布占位文案列出具体缺失项（"还差：选择透视表行维度"），数据从 `ready()` 的检查逻辑里带出来。

**🟡 U7. 不能复制。**
不能复制区块（改个分组字段就是一张新图，现在要从零配）、不能复制页签、列表页不能"另存为"复制整张报表。建议区块头加复制按钮 + 列表页操作列加「复制」。

**⚪ U8. 顶栏页签区在窄屏挤压、页签多时横向滚动无提示；快捷键缺失（Ctrl+S 保存）。**

### 3.3 概念理解

**🔴 U9. "全局口径 vs 块级时间范围 vs 块级日期字段"三层概念缺少就地解释。**
本次迭代中已暴露出配置项"藏起来用户就以为没有"的问题（下钻设置曾只在按字段分组时显示，已修复为常显）。时间体系同理：块级"时间范围 = 跟随全局口径"的下拉默认值对新手不可解释。
**建议**：块级时间范围 label 旁加 `?` 提示图标，一句话说清覆盖关系；全局口径下拉在顶栏已有「全局时间」label（2026-09-29 已加），设置抽屉里的重复配置项可标注"与顶栏联动"。

**🟡 U10. 数据集概念隐性。**
"每张表只能建一个数据源"、"数据集名称要在抽屉里改"、"筛选块的'同数据源'作用域"——这些规则用户只能从报错里学。建议侧栏数据源分组头部加编辑入口提示，数据集重命名支持双击内联改。

**🟡 U11. 绘制失败只在 toast 里一闪而过。**
草稿运行 400 时画布无块级错误定位。建议把后端校验错误映射到块 id 上，画布卡片头标红点，点开看原因（工作流的"保存前体检标注到节点"同款思路）。

### 3.4 查看端

**🟡 U12. 明细表改全量返回后，大表有性能风险。**
2026-09-29 已取消明细表条数上限（全量返回 + 客户端分页 50/页）。几百到几千行没问题；上万行的表会让 `run` 接口变慢、前端一次渲染 50 行但内存持有全量。
**建议**：中期改为服务端分页（run 接口给 table 块加 page/page_size 参数），这是兼顾"不限条数"与性能的正式解法。

**🟡 U13. 筛选块之间不联动。**
选了"区域=华东"后，"城市"筛选块的可选项不会收缩。业界轻量产品（DataEase/简道云）普遍支持同数据集筛选级联。

**🟡 U14. 下钻明细只有一层、且不可再操作。**
下钻弹窗是终点：不能从明细再跳记录编辑、不能再下钻。建议明细表行加"打开记录"链接（跳 `/t/{table_id}` 定位行），闭环回业务数据。

**⚪ U15. 移动端（小程序）报表是查看级体验**，不支持筛选/下钻的完整交互，窄屏单列降级可用但图表偏小。可接受，随小程序整体迭代。

### 3.5 分发分享

**🟡 U16. 分享页隐藏筛选组件，接收方只能看死数据。**
`ReportDashboard` 在分享场景 `filterable=false`（筛选块不渲染）。被分享人最常见的动作恰恰是"我想看下上个月的"。建议：分享链接创建时可选"允许查看者筛选/切换口径"（默认关，安全优先）。

**🟡 U17. 推送内容不可预览。**
配了邮件/webhook 推送，只有到点发了才知道长什么样。设置抽屉加「发送测试推送」按钮（后端 `test-push` 接口已存在，前端设计器里没入口）。

**⚪ U18. 导出 HTML 是静态快照，图表为截图级体验**；Excel 导出已是矩阵平铺，够用。
