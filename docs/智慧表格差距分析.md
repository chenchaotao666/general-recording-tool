# 智慧表格 · 参照设计差距分析

> 参照：`docs/智慧表格/` 下约 100 张截图（飞书/钉钉多维表格风格产品）。
> 现状：`frontend/src/views/smart/` + `frontend/src/components/smart/`。
> 目标：**页面样式、组件、布局、图标做到几乎一样**。
> 本文档按"设计令牌 → 图标体系 → 页面骨架 → 表格本体 → 单元格 → 面板/弹窗 → 菜单 → 功能缺口"逐层对比，每项给出 参照 / 现状 / 差距 / 优先级。
>
> 优先级定义：**P0** = 纯视觉对齐（改样式/图标即可，不动功能）；**P1** = 组件结构调整（有开发量，不改数据模型）；**P2** = 功能补齐（需新功能/后端配合）。

## 1. 图标体系（差距最大、收益最高的单点）

### 1.1 现状问题：三套并存

| 用途 | 现状实现 | 问题 |
|---|---|---|
| 表头字段图标 | `fieldIcons.js` 16×16 线性 SVG ✓ | 方向正确，但图形与参照象形不一致（见 1.3） |
| 面板/弹窗/记录详情 | `fieldRegistry.js` 的 emoji/Unicode 字符（`📅👤🔗🖼📁☑fx`） | 与参照的线性灰图标完全两个物种 |
| 表格设置面板 | `FieldTypeIcon.vue` 徽章字形 + Element 图标 | 第三套 |
| 工具栏/菜单图标 | Unicode 字符（`＋▦⧩≡⇅⇕🖌📌⊖✏❄🚫⧉⇥↶↷🔍`） | 粗细/风格/渲染随平台漂移，参照全部为 1.5px 线性 SVG |

### 1.2 参照规范

- **全部细线性图标**：线宽 ≈1.5px，深灰 `#646A73`（或随文字色），菜单内 16px，字段类型 14px。
- 唯一彩色例外：紫色 AI 花形/星形图标；通讯录/群场景用蓝色面性方块图标；动作类型用彩色实心小方块（绿=新建/触发、黄=消息、橙=修改、紫=查找）。
- 删除图标（垃圾桶）也**不用红色**，危险色仅用于极少量文字场景。

### 1.3 字段类型图标对照（参照象形 → 需重绘 SVG）

文本=方框内"A"；单选=圆圈内含对勾；多选=对勾+三条横线（checklist）；数字=错落"123"；百分数="%"；货币=圆圈内"¥"；进度=两段式横条（一长一短）；日期=日历（矩形+顶部两挂耳+点阵）；人员=单人轮廓；群聊=双人叠影轮廓；图片=相框+山形；文件=折角文档；关联=相扣两方框/表格链环；链接=链条环；电话=听筒轮廓；邮箱=信封（矩形+倒V）；地理位置=定位针；复选框=方框内对勾；条码=竖条码；自动编号="1↓"；公式=斜体"fx"（衬线感）；查找引用=表格+放大镜；创建人/最后编辑人=单人轮廓；创建时间/最后编辑时间=日历。

**行动**：
1. 建一套统一 SVG 图标组件（如 `smart/icons/` 下每图标一个 SVG，`stroke: currentColor; stroke-width:1.5`），替换三套并存的实现。**P0**
2. 工具栏/菜单全部 Unicode 字符替换为同款线性 SVG（漏斗、分组层叠、排序双箭头、行高、油漆桶、图钉、⊖、铅笔、雪花→冻结角标、眼睛斜线、双方块、垃圾桶、撤销/重做弯箭头、放大镜、四角全屏、时钟历史）。**P0**
